# «قصة الموقع | النشأة والتطور والسجل التاريخي» (طلب المدير، ٢١ نوفمبر ٢٠٢٦)

- **المسار:** `#/story` (story.js). للإدارة وحدها مبدئيًّا (`STORY_PUBLIC = false`)؛ والزائر يرى النسخة الموجزة وعبارة «قيد الإعداد والمراجعة».
- **النسخة الموجزة العامة:** `STORY.brief()` في صفحة التعريف (`#/about`) بلا أسماء أشخاص ولا مبالغ.
- **المصادر:** رواية المؤسس في طلبه، وسجل git (أول رفع ٢٢ أكتوبر ٢٠٢٦)، وHANDOFF.md، وDECISIONS.md، وabout.js. لا تاريخ ولا مبلغ ولا حدث إلا ما ثبت؛ وما لم يُقيَّد تاريخه ذُكر بمرحلته.
- **الأقسام:** النشأة، بداية التنفيذ، الغاية الكبرى، الخط الزمني (TL)، اثنتا عشرة محطة (STATIONS) بحالة كل خدمة (done/part/dev/wait)، المساهمات (GIFTS)، المصاريف (COSTS)، الأرقام (SNAP لقطة مؤرخة + أعداد حية من الفهرس)، «من فكرة إلى أثر»، «رؤية المستقبل» (FUTURE)، وطباعة.
- **الإضافة لاحقًا:** عنصر جديد في TL أو STATIONS[i].items أو GIFTS أو COSTS أو FUTURE في story.js، وتحديث SNAP بتاريخه.
- **النشر للعموم:** `STORY_PUBLIC = true` بعد مراجعة المدير. تنبيه: المستودع عام، فمحتوى story.js (ومنه المساهمات والمبالغ) مقروء على GitHub وإن أخفته الواجهة.
