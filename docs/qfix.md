# طلب تصحيح الأسئلة في الموقع كله (طلب المدير، ٢١ نوفمبر ٢٠٢٦)
- **اعتماد مبدئي:** اعتُمدت أسئلة بنك الطلائع الأولى كلها (١٤٢) بـ`okby: "admin-bulk"`، فتدخل الألعاب الآن؛ وما يظهر فيه خطأ يُصحَّح أو يُستبعد.
- **qfix.js:** تحت كل سؤال في الموقع زر «⚑ طلب تصحيح» يُضاف آليًّا لعناصر الأسئلة المعروفة (`.talaq` الطلائع، `.tpq` ألعاب الطلائع، `.msbq` المِسبار، `.qq` اختبارات الكتب، `.qaq` سؤال وجواب، `.tmq` التمارين وقصص الطلائع، `section.q > .qt` نتائج الاختبار)؛ فيشمل كل اختبار جديد يستعمل هذه الأصناف.
  - **بشريًّا:** العضو يكتب الخطأ والصواب ومصدره ← جدول `corrections` (`book_id = "q:<المسار>"`، `page = 0`، `proposed` = JSON بالسؤال وخياراته والمراجعة الآلية) ← «الإدارة ← تصحيحات القراء» (بطاقة خاصة: موضعه، والملاحظة، والمراجعة الآلية، و«صُحّح» أو «رفض»)، وإشعار تليجرام (kind=corr).
  - **آليًّا:** «🤖 مراجعة آلية» (api/edit.js mode=qcheck): حكم موجز (سليم / يحتاج تصحيحًا) وملاحظة ومقترح، يُرفق بالطلب.
  - **المدير:** «✎ تعديل (للإدارة)» لأسئلة بنك الطلائع المتجدد: تعديل السؤال والجواب والخيارات والتعليل مباشرة أو استبعاده (GH.editJSON على data/tala-bank.json)؛ وللأسئلة الثابتة أو المولَّدة من النصوص يُرسل الطلب ويُصحَّح من مصدره.
- لا ترحيل لقاعدة البيانات: يُستعمل جدول corrections القائم وسياساته (العضو يُدرج طلبه، والإدارة تقرأ وتحدّث).
