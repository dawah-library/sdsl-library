# استجلاب منشورات فيسبوك لحسابات تختارها الإدارة

**الإدارة ← مراجعة المستجلب ← حسابات فيسبوك**: تضيف الإدارة الحساب (الاسم، رابط الصفحة أو اسمها، النوع: صفحة/شخصية/مجموعة، القسم، طريقة النشر، والمؤلف في المكتبة)، فيُحفظ في data/sources.json بنوع `facebook`.

## الجلب الآلي (صفحات فيسبوك)
- يعمل مع الاستجلاب الدوري (sources.yml) عبر واجهة فيسبوك الرسمية Graph API: `/{page}/posts?fields=message,created_time,permalink_url`.
- يحتاج رمز وصول من الصفحة (Page Access Token بصلاحية `pages_read_engagement`) يمنحه مدير الصفحة لتطبيق المكتبة على developers.facebook.com.
- تُحفظ الرموز سرًّا في GitHub ← Settings ← Secrets ← `FB_TOKENS` بصيغة JSON: `{"fb-pagename": "الرمز"}` (المعرّف يظهر في قائمة الحسابات)، أو `FB_PAGE_TOKEN` رمزًا واحدًا عامًّا.
- كل منشور جديد يدخل «مراجعة المستجلب» ولا يُنشر قبل الاعتماد؛ والمنشورات القصيرة (أقل من ٣٠٠ حرف) تُتخطى.

## الحسابات الشخصية وما لا رمز له
- فيسبوك لا يتيح قراءة منشورات الحسابات الشخصية لتطبيقات أخرى، ولا يُستعمل الزحف ولا الحسابات الوهمية (مخالف للشروط ويُحجب).
- تُضاف منشوراتها من نموذج «إضافة منشور من فيسبوك يدويًّا» (الرابط والنص والتاريخ)، فتدخل المراجعة بالمسار نفسه.
- طرق مشروعة أخرى: قناة تليجرام عامة للشخص (t.me/s/…) أو موقعه، فتُضاف مصدرًا عاديًّا.
