# استجلاب محتوى صفحات بعينها على فيسبوك (ب4-20)

فيسبوك لا يتيح قراءة صفحات الغير آليًا بلا إذن، ونسخ الصفحات بالزحف مخالف لشروطه ويُحجب سريعًا. الحلول المشروعة بالترتيب:

1. **إذن الصفحة عبر Graph API (الأفضل):** يمنح مدير صفحة «مركز جسور» تطبيق المكتبة صلاحية `pages_read_engagement` (أو يضيف حساب المكتبة محررًا)، فيقرأ الاستجلاب منشوراتها برمز الصفحة. يتطلب إنشاء تطبيق على developers.facebook.com وموافقة صاحب الصفحة؛ ويُحفظ الرمز سرًّا في GitHub (FB_PAGE_TOKEN) لا في المستودع.
2. **مصدر موازٍ:** كثير من المراكز تنشر الأبحاث نفسها على موقع أو قناة تليجرام أو ملفات PDF؛ يُستجلب منها بالمهمة العامة (data/sources.json) أو بقناة تليجرام عامة (t.me/s/اسم_القناة صفحة ويب عامة قابلة للقراءة).
3. **الإرسال من المركز:** بريد أو نموذج في الموقع يرسل منه المركز روابط أبحاثه أو ملفاتها، فتدخل قائمة «مراجعة المستجلب».
4. **الإدخال اليدوي:** يضيف المشرف رابط المنشور ونصه وملخصه من «الإدارة ← إضافة مقال» بقسم «المصادر الإثرائية» ومصدر «مركز جسور».

لا يُستعمل الزحف على فيسبوك ولا حسابات وهمية. وإن لم يأذن المركز بإعادة النشر كاملًا فيُعرض الملخص والبيانات والرابط الأصلي فقط (ب4-30).
