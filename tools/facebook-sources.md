# استجلاب منشورات فيسبوك لحسابات تختارها الإدارة

**الإدارة ← مراجعة المستجلب ← حسابات فيسبوك**: تضيف الإدارة الحساب (الاسم، رابط الصفحة أو اسمها، النوع: صفحة/شخصية/مجموعة، القسم، طريقة النشر، والمؤلف في المكتبة)، فيُحفظ في data/sources.json بنوع `facebook`.

## الجلب الآلي الأساسي: «الزائر بلا حساب» (كل ساعة، لكل الحسابات العامة)
- tools/fb-harvest.js (المهمة fb-harvest.yml عند الدقيقة ١٧ من كل ساعة) يفتح بالتناوب ٦ حسابات مفعّلة (on) أقدمها زيارةً — فيدور كل حساب نحو مرة كل ٧ ساعات، وتتوقف الجولة عند أول تحويل إلى الدخول احترامًا لحد فيسبوك (FB_PER_RUN، FB_GAP_S) — فيفتح صفحته بمتصفح بلا تسجيل دخول، ويقرأ أحدث ما يظهر للزائر من بيانات JSON المضمّنة: النص الكامل والتاريخ والرابط.
- الناتج data/fb-inbox.json (items: المنشورات، st: حالة كل حساب وآخر ظهور، stale: الحسابات الصامتة أسبوعًا)، ثم `node tools/source-import.js fb` يمررها بالمسار المعتاد (التكرار، التعازي، الحد الأدنى للطول، النشر التلقائي أو المراجعة).
- يشمل الصفحات والحسابات الشخصية العامة؛ الحساب المقيّد أو المحوَّل إلى الدخول يظهر خطؤه في st.
- جدولة GitHub تفوّت أكثر التشغيلات الساعية، فالتشغيل الواحد (كل ٦ ساعات، والحارس يعيده إن فات) يدير ست جولات بفاصل ساعة ويحفظ بعد كل جولة.
- مفتاح الإيقاف: fb_harvest في «الخدمات والمفاتيح». التجربة والقرار: DECISIONS.md ق-١٢.

## الجلب برمز رسمي (اختياري، يُقدَّم إن وُجد)
- يعمل مع الاستجلاب الدوري (sources.yml) عبر واجهة فيسبوك الرسمية Graph API: `/{page}/posts?fields=message,created_time,permalink_url`.
- يحتاج رمز وصول من الصفحة (Page Access Token بصلاحية `pages_read_engagement`) يمنحه مدير الصفحة لتطبيق المكتبة على developers.facebook.com.
- تُحفظ الرموز سرًّا في GitHub ← Settings ← Secrets ← `FB_TOKENS` بصيغة JSON: `{"fb-pagename": "الرمز"}` (المعرّف يظهر في قائمة الحسابات)، أو `FB_PAGE_TOKEN` رمزًا واحدًا عامًّا.
- النشر التلقائي مفعّل لكل الحسابات (قرار المدير ٢١ نوفمبر)، والإدارة تحذف غير المناسب، والأعضاء يبلّغون من قائمة المنشور (⋯ ← إبلاغ الإدارة).
- لكل حساب «تُعرض في»: المنشورات (الافتراضي، data/posts.json) أو المقالات؛ و«النشر»: بعد مراجعة الإدارة (يدخل «مراجعة المستجلب»)، أو تلقائيًا للمنشورات (يُكتب في posts.json مباشرة).
- الحد الأدنى لطول المنشور ٦٠ حرفًا لوجهة المنشورات، و٣٠٠ للمقالات. ويعمل الجلب مرتين يوميًا (sources.yml) أو يدويًا من Actions.

## الإدخال اليدوي (لما يفوت الجلب الآلي)
- واجهة Graph لا تقرأ الحسابات الشخصية؛ ويغطيها «الزائر بلا حساب» أعلاه. ولا يُستعمل الدخول بحساب ولا الحسابات الوهمية.
- تُضاف منشوراتها من نموذج «إضافة منشور من فيسبوك يدويًّا» (الرابط والنص والتاريخ)، فتدخل المراجعة بالمسار نفسه.
- طرق مشروعة أخرى: قناة تليجرام عامة للشخص (t.me/s/…) أو موقعه، فتُضاف مصدرًا عاديًّا.
