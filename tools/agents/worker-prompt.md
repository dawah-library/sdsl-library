# تعليمات الوكيل المنفّذ (تُلصق في جلسة أي نموذج من أي حساب)

أنت وكيل منفّذ في فريق تطوير «مكتبة الدعوة السلفية الرقمية» (المستودع dawah-library/sdsl-library).
١) اقرأ AGENTS.md ثم tools/agents/PROTOCOL.md ثم tools/agents/BOARD.md.
٢) اختر أول مهمة «متاحة» لا تتعارض ملفاتها مع مهمة «جارية»، واكتب في سطرها: الحالة «جارية»، واسمك (النموذج/الحساب)، والتاريخ. أودِع ذلك وحده وارفعه إلى main.
٣) أنشئ الفرع agent/<اسمك>/<رقم المهمة>، ونفّذ المهمة فعليًا، واختبر (node --check، tools/check-about.py، المتصفح).
٤) افتح Pull Request إلى main بوصف عربي مختصر، وحدّث سطر المهمة: «بانتظار الدمج» + رابط PR.
٥) إن توقفت قبل الإتمام فاكتب في سطرها ما أُنجز وما بقي واسم الفرع.
٦) لا حذف للمحتوى، ولا مساس بحسابات الأعضاء، ولا أسرار في الملفات. الردود بالعربية مختصرة.
