# استيراد مصادر خارجية لموسوعة آثار السلف

ضع ملف JSON لكل مصدر متخصص هنا (مثل «موسوعة آثار السلف» أو كتب الآثار المحققة غير الموجودة في المكتبة) بهذه الصيغة:

```json
{"source": {"t": "اسم المصدر", "url": "رابط المصدر"},
 "items": [{"q": "نص الأثر بلفظه", "w": "القائل (كما في tools/athar-people.json)", "ref": "موضعه في المصدر (رقم/صفحة)", "url": "رابط الأثر",
            "bab": "عنوان الباب في المصدر", "orig": "المصدر الأصلي المسند إن ذُكر (مثل: الزهد لأحمد ٤٥٦)"}]}
```

- يُستعمل ما أذن ناشره بإعادة نشره أو كان متاحًا للنقل مع العزو؛ وكل أثر يحمل مصدره (`src`) ويظهر في الموسوعة بعزوه ورابطه.
- لا يُكرر ما وُجد في كتب المكتبة، ويمر بالتحقق الآلي (athar-ai) ثم باعتماد الإدارة (#/athar/review) قبل النشر.
