# سجل مهام وثيقة التطوير الشاملة

> المرجع: «الوثيقة التنفيذية الشاملة الجديدة» (أبواب ١–٣٤ وملحق Vercel). أُنشئ ٣٠ أكتوبر ٢٠٢٦ بعد فحص المستودع وVercel وSupabase.
> الحالات: ✅ مكتملة ومختبرة · 🟡 جزئية (موجود يحتاج استكمالًا) · ⬜ لم تبدأ · ⛔ تحتاج تدخلًا إداريًا أو خدمة خارجية.
> قاعدة: لا تُنشأ خدمة موجودة؛ تُختبر وتُصلَح وتُوسَّع.
> **السجل التفصيلي:** tools/plan-tasks.json — كل بنود الوثيقة (١٩٤٧ بندًا) مستخرجة آليًا بحالاتها، ومنشور صفحةً تفاعلية «سجل تنفيذ مكتبة الدعوة السلفية الرقمية». هذا الملف ملخص بالأبواب.

## البنية الحالية (نتيجة الفحص)
- واجهة PWA بلا إطار (index.html + ١٦ ملف JS + style.css)، تُنشر من GitHub (main) إلى Vercel Hobby.
- ١٢ دالة في api/ (الحد المجاني ١٢ — يُدمج لا يُضاف).
- Supabase (nqxkkdexpodjjwfdkxoq، Postgres 17): الحسابات والمجتمع والتعليقات والإشعارات وخطط القراءة وsrs_decks.
- المحتوى ملفات JSON في المستودع (data/catalog.json: ٥٥٤ كتابًا و٢٠٠ مؤلف؛ data/articles: ≈٥٠١٠ مقالًا)، والمجلدات الكبيرة وصور الصفحات خارج Vercel (raw.githubusercontent وR2).
- المعالجة الثقيلة في GitHub Actions (OCR، التشكيل، التشجير، الاستيراد، الترجمة، الفهارس).
- ٢٧ نشرًا يوميًا تقريبًا، كلها من المهام الآلية.
