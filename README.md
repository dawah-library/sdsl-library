# مكتبة الدعوة السلفية الرقمية — دليل النشر والتفعيل

## محتويات المشروع
| الملف | الوظيفة |
|---|---|
| `index.html`, `style.css`, `app.js` | الموقع |
| `search.js` | محرك البحث (يستعمله الموقع والخادم معًا) |
| `config.js` | الإعدادات: رابط الموقع، مفاتيح الحسابات |
| `data/catalog.json` | فهرس المكتبة: المؤلفون، الأقسام، الكتب والمقالات (بيانات فقط) |
| `data/books/<id>.json` | نص كل كتاب أو مقال في ملف مستقل، يُحمَّل عند فتحه فقط |
| `data/dict/mukhtar.json` | معجم مختار الصحاح لشرح الكلمات داخل القارئ |
| `api/ask.js` | خادم «اسأل المكتبة» |
| `api/import.js` | خادم استيراد المقالات من صوت السلف |
| `tools/merge-update.js` + `.github/workflows/merge-updates.yml` | دمج التحديثات تلقائيًا |
| `sw.js`, `manifest.webmanifest` | العمل دون إنترنت والتثبيت كتطبيق على الهاتف |

## 1) النشر على Vercel
1. أنشئ مستودعًا على GitHub باسم الجمعية وارفع محتويات هذا المجلد كلها (ومنها مجلد `.github`).
2. vercel.com ← Add New ← Project ← استورد المستودع ← Deploy.
3. اربط الدومين من Settings ← Domains، وضع الرابط في `siteUrl` داخل `config.js` (يظهر في القبسات والنصوص المنسوخة).

## 2) استيراد مقالات صوت السلف
بعد النشر: الإدارة ← «استيراد من صوت السلف». القائمة معبأة بأحدث المقالات؛ أضف أي روابط أخرى.
يجلب الخادم كل مقال ويستخرج العنوان والكاتب والتاريخ والقسم والنص، **فتراجعه وتصححه ثم تحفظه**.
الاستخراج آلي من صفحة الموقع، فقد يحتاج تعديلًا يسيرًا إن تغيّر تصميم صوت السلف.

## 3) نشر ما تضيفه للجميع (ملف التحديث)
ما تضيفه أو تعدّله من صفحة الإدارة يُحفظ على جهازك. لنشره:
1. الإدارة ← «ملف التحديث» ← «تنزيل ملف التحديث».
2. في GitHub: افتح مجلد `updates` ← Add file ← Upload files ← ارفع الملف ← Commit.
3. يدمجه GitHub Actions تلقائيًا في بيانات المكتبة، ثم يعيد Vercel النشر خلال دقائق.
(يمكن تجربة الدمج يدويًا: `node tools/merge-update.js`)

## 4) تفعيل «اسأل المكتبة»
1. أنشئ حسابًا في console.anthropic.com باسم الجمعية، واشحن رصيدًا، وأنشئ مفتاح API، وضع حدًا شهريًا للإنفاق.
2. في Vercel ← Settings ← Environment Variables أضف `ANTHROPIC_API_KEY`، و(اختياريًا) `SDSL_HOURLY_LIMIT` لعدد الأسئلة لكل عضو في الساعة (الافتراضي 30).
3. Redeploy.

## 5) الحسابات الحقيقية والدخول بحساب Google وApple (Supabase)
بدونها تعمل الحسابات في «وضع تجريبي» على جهاز الزائر فقط.
1. أنشئ مشروعًا مجانيًا في supabase.com، ثم من SQL Editor ← New query الصق محتوى الملف `supabase/schema.sql` كاملًا واضغط Run. ينشئ: الحسابات وصلاحياتها (عضو، محرر، مدير)، ومحادثات «اسأل المكتبة»، وتصحيحات القراء، وتفاعل الأعضاء مع المنشورات (إعجاب، تعليق، حفظ). ثم سجّل الدخول في الموقع مرة، ونفّذ السطر الأخير في الملف ببريدك لتصير مديرًا (فيظهر لك تبويب «تصحيحات القراء» في الإدارة).
2. من Project Settings ← API انسخ `Project URL` و`anon public key`: ضعهما في `config.js`، وأضفهما في Vercel باسم `SUPABASE_URL` و`SUPABASE_ANON_KEY`.
3. Authentication ← URL Configuration: ضع رابط موقعك في Site URL وRedirect URLs.
4. **الدخول بحساب Google (مجاني):** في Google Cloud Console أنشئ «OAuth client ID» من نوع Web، وضع فيه رابط الرجوع الذي تعرضه Supabase في Authentication ← Providers ← Google، ثم الصق Client ID وSecret هناك وفعّله.
5. **الدخول بحساب Apple:** يحتاج حساب Apple Developer (اشتراك سنوي مدفوع)؛ أنشئ Services ID ومفتاح Sign in with Apple، وأدخلها في Supabase ← Providers ← Apple.
عند تفعيل المزوِّد يظهر للزائر اختيار حسابه المسجل على هاتفه بضغطة واحدة.

## 6) الاستيراد اليومي الآلي لمقالات صوت السلف
- يعمل تلقائيًا كل يوم عبر GitHub Actions (`.github/workflows/daily-import.yml`) فيستورد دفعة من المقالات **بدءًا من الأقدم** (رقم 1 فصاعدًا)، ثم يحفظ النتيجة في المستودع فيعيد Vercel النشر.
- موضع التقدم وحجم الدفعة في `data/import-state.json`: `next` رقم المقال التالي، و`perRun` عدد المقالات يوميًا (150 افتراضيًا)، و`delayMs` المهلة بين الطلبات حتى لا نثقل على موقع صوت السلف.
- كل كاتب جديد يُضاف تلقائيًا إلى «المؤلفون» (معرّفه يبدأ بـ w) بصفحة فيها تبويبا الكتب والمقالات، لتُرفع كتبه لاحقًا. أكمل نبذته واسمه الكامل من `data/catalog.json` عند الحاجة.
- تُصنف المقالات بقسمها في صوت السلف؛ وما لم يُعرف قسمه يوضع في «غير مصنف»، والفتاوى في «فتاوى واستشارات».
- التشغيل اليدوي (مثلًا لأول تجربة): المستودع ← Actions ← «الاستيراد اليومي لمقالات صوت السلف» ← Run workflow، واكتب عدد المقالات.
- تُخزن المقالات في ملفات شهرية `data/articles/YYYY-MM.json` وفهرس `data/articles/index.json`. عند تجاوزها عشرات الآلاف يُنقل التخزين والبحث إلى قاعدة بيانات (Supabase).

## المحتوى الحالي
- **تراث (25 كتابًا بنصوص كاملة):** التفسير (السعدي)، علوم القرآن (مقدمة ابن تيمية، الإتقان)، الحديث (البخاري، مسلم، الموطأ، رياض الصالحين، الأربعون النووية)، علوم الحديث (مقدمة ابن الصلاح، البيقونية)، الفقه (عمدة الفقه، بلوغ المرام)، أصول الفقه (الورقات)، العقيدة (الطحاوية، الواسطية، لمعة الاعتقاد، شرح السنة، كتاب التوحيد)، اللغة (قطر الندى، ألفية ابن مالك، مختار الصحاح)، الأدب (أدب الدنيا والدين، الأدب المفرد)، التاريخ (تاريخ الخلفاء)، السيرة (الفصول لابن كثير).
- **مكتبة الدعوة:** «علو الهمة» للشيخ محمد إسماعيل المقدم و«من أعلام السلف» للشيخ أحمد فريد بنصوصهما الكاملة، إضافة إلى عناوين تجريبية.
- المصدر: المكتبة الشاملة عبر مشروع OpenITI المفتوح (رخصة CC BY-NC-SA 4.0: ذكر المصدر وعدم الاستخدام التجاري). كتب المشايخ المعاصرين تحتاج إذنًا من أصحابها أو من الجمعية قبل النشر العام.
- العناصر المعلّمة `"demo": true` في `catalog.json` نصوص تجريبية مستبعدة من بحث المساعد؛ احذفها أو استبدل نصها.

## ملاحظات
- الترجمة الآلية مجانية ومحدودة يوميًا، وتخطئ في المصطلحات الشرعية، وعليها تنبيه في الواجهة.
- صفحة الإدارة غير محمية بكلمة مرور في هذه النسخة، لكنها لا تغيّر الموقع المنشور إلا عبر رفع ملف التحديث إلى GitHub.
- عند تجاوز المكتبة بضعة آلاف كتاب يُنقل البحث إلى قاعدة بيانات (Postgres أو Meilisearch).
