# الخطوط المستضافة ذاتيًا (للقارئ)
كلها برخصة SIL Open Font License 1.1 التي تجيز الاستضافة والتضمين؛ نص كل رخصة في licenses/ من مستودع الخط نفسه:
- أميري: https://github.com/aliftype/amiri (عبر google/fonts/ofl/amiri)
- كتاب (Kitab): https://github.com/nuqayah/kitab-font (مبني على شهرزاد SIL، قريب من نسخ الطباعة التقليدية)
- شهرزاد الجديد، لطيف: SIL، عبر google/fonts/ofl
- نوتو نسخ عربي، مركزي: عبر google/fonts/ofl
قُلِّصت (subset) إلى العربية بتشكيلها والأشكال التقديمية واللاتينية الأساسية والترقيم مع كل خصائص الخط (GSUB/GPOS)، وحُوِّلت إلى woff2.
